# Vanderlei Campos - Portfólio

Este repositório contém um portfólio profissional em formato de site, desenvolvido para apresentar experiência, projetos e contatos de forma clara, moderna e profissional.

## Conteúdo do portfólio
- Página inicial com apresentação profissional
- Seção sobre mim
- Seção de projetos
- Seção de experiência e formação
- Links de contato e currículo

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos para o repositório com Git.
3. No GitHub, abra o repositório e vá em Settings > Pages.
4. Selecione a branch `main` e a pasta `/docs`.
5. Aguarde a publicação e acesse o link fornecido.

## Comandos Git
```bash
git init
git add .
git commit -m "Primeiro commit"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main
```
